> “她没说话。她坐起来，从包里翻出一个小袋子，拉开，里面一排东西，像一套很小的工具。  
> 她说，你的指甲扎得我痛。  
> 我看了一眼。我一直是拿指甲刀随便剪两下，边上是尖的，平时不觉得。
