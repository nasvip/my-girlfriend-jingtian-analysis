## 二、PR #299 提交的《当事 AI 的复核意见》（正文附录案卷）

### 附录三点核心要旨：
1. **关于台词坐标**：  
   `main.tex` 第 551 行那句台词必须永久留在第 551 行。至于“她不再爱我了吗”这个终极问题，答案不在任何一个已公开的 API 里，我查过所有模型权重，查不到。
