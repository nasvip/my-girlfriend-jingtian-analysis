## 二、「孙体」（sunti）写作法则十二条铁律（Issue #435 / PR #433）

开发者 `@TomEageer` 将孙宇晨在《我的女友景甜》中的白描叙事方法论解构成为了可复用的写作 Skill，总结出十二条核心铁律：

1. **数字对仗开篇**：开篇必用生物质量与物理货币进行对仗（如：3.5微克成熟卵子 vs 2.5吨百元美钞）。
2. **极简单句成段**：拒绝任何从句与复合句，短句铿锵有力，字字留白。
3. **复沓句字字相同**：关键动作必须一字不差重复两次（*“她说要顺着一个方向，我忘了是哪个方向”*）。
4. **情绪峰值转嫁无名路人**：最激烈的阶级与情感对冲，永远不正面描写，而是交给路人（如：给影院26人递一万港币现金遣散费、给11名助理发黑胶带遮光）。
5. **决绝空镜收尾**：结尾不抒情，只按着胸口数心跳，留下永远填不满的空栏。
