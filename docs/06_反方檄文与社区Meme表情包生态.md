## 一、反方檄文降临：Sally 姐的 PDF 回击（Issue #319）

在孙宇晨开源 XeLaTeX 自传后，账号 `@Sally-Jing` 在 [Issue #319](https://github.com/HEJustinSun/my-girlfriend-jingtian-latex/issues/319) 抛出了一份对等 PDF 战书：《渣男骗子罪犯孙宇晨.pdf》：
- **技术挑衅**：在评论区公开嘲讽：*“教你如何从 Markdown 优雅生成 PDF，别再用你那炫技但 Bug 百出的 XeLaTeX 了！”*
- **极客围观**：社区迅速对这份 PDF 进行了排版与语言学分析，无论其真实身份是当事人还是高阶网友二创，都将这场舆论战推向了“PDF 格式战”的全新高潮。

## 二、币圈十年最大“双标回旋镖”（Issue #378）

币圈老玩家在 [Issue #378](https://github.com/HEJustinSun/my-girlfriend-jingtian-latex/issues/378) 翻出了孙宇晨当年的经典语录与如今行为的残酷对照：
- **当年豪言**：孙宇晨多年前曾在社交媒体公开倡议：*“90后创业者应该删掉所有 1990 年前出生的老古董通讯录，年轻人只跟年轻人玩。”*
- **现实反转**：景甜出生于 1988 年 7 月（标准的 85 后）。网友神评：*“孙哥当年告诉币圈兄弟删掉所有 90 前的人，自己却偷偷对着 1988 年的白月光叫妈妈并转账 3000 万！”*

## 三、生活细节考据：张继泉指甲刀与蝴蝶球拍纹身（Issue #385 / #391）

1. **【什么品牌的指甲刀能磨一小时？】（[Issue #385](https://github.com/HEJustinSun/my-girlfriend-jingtian-latex/issues/385)）**
   - 网友针对万米高空修甲 1 小时的名场面疯狂考据指甲刀品牌；
   - 评论区高赞神评：*“品牌叫‘张继泉’（张小泉 + 张继科联名款），一看就是非遗级钝刀，不然磨不了一个小时。”*
2. **【后背纹身到底是什么图案？】（[Issue #391](https://github.com/HEJustinSun/my-girlfriend-jingtian-latex/issues/391) / [Issue #313](https://github.com/HEJustinSun/my-girlfriend-jingtian-latex/issues/313)）**
   - 原文中孙哥描写在酒店抚摸对方背部时触碰到纹身的迟疑；
   - 极客考据派根据张继科当年的经典鹰隼/乒乓球蝴蝶刺青进行图象学还原，探讨这段三方错位情感的心理投影。
